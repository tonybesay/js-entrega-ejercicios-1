# Entrega de Ejercicios · JavaScript Vanilla

## 🌐 Demo online

Puedes ver el proyecto funcionando en el siguiente enlace:

👉 **https://tonybesay.github.io/js-entrega-ejercicios-1/**

Repositorio correspondiente a la entrega de ejercicios prácticos de **JavaScript Vanilla**, realizados como parte del máster de **Desarrollo Full Stack – ConquerBlocks**.

El objetivo de esta entrega es afianzar los fundamentos de JavaScript mediante ejercicios progresivos centrados en la manipulación del DOM, gestión de eventos, lógica de programación y persistencia de datos en el navegador.

---

## 🧠 Ejercicios realizados

### Ejercicio 1 · Cambiador de background
Aplicación sencilla que cambia el color de fondo de la página al hacer click en un botón.  
Se trabajan eventos de click y manipulación básica del DOM.

---

### Ejercicio 2 · Contador de clicks
Contador que incrementa su valor cada vez que el usuario pulsa un botón.  
Permite practicar:
- Captura de eventos
- Actualización dinámica del contenido en pantalla
- Manejo de estado básico en JavaScript

---

### Ejercicio 3 · Lista dinámica con eliminación
Creación de una lista de elementos a partir de un input de texto.  
Cada elemento puede eliminarse individualmente mediante un botón asociado.

---

### Ejercicio 4 · Filtro de búsqueda en tiempo real
Filtrado dinámico de una lista (array de animales) según el texto introducido por el usuario.  
El listado se actualiza automáticamente conforme se escribe.

---

### Ejercicio 5 · Calculadora básica
Calculadora con las operaciones principales:
- Suma
- Resta
- Multiplicación
- División  

Incluye validaciones de entrada y control de errores.

---

### Ejercicio 6 · Temporizador
Temporizador con los siguientes controles:
- Iniciar
- Pausar
- Reiniciar  

Se trabaja el uso de `setInterval`, gestión de estado y renderizado del tiempo en formato `HH:MM:SS`.

---

### Ejercicio 7 · Generador de contraseñas
Generador de contraseñas aleatorias que combina:
- Letras mayúsculas
- Letras minúsculas
- Números
- Caracteres especiales  

Incluye validación de longitud mínima y mensajes de error.

---

### Ejercicio 8 · Contador de palabras y caracteres
Contador en tiempo real que muestra:
- Número de palabras
- Número de caracteres  

Se actualiza automáticamente conforme el usuario escribe en un textarea.

---

### Ejercicio 9 · Lista de tareas con LocalStorage
Aplicación de lista de tareas que permite:
- Añadir tareas
- Marcar tareas como completadas
- Eliminar tareas completadas
- Persistir los datos mediante `localStorage`  

Las tareas se mantienen incluso tras recargar la página.

## ▶️ Ejecución del proyecto

El proyecto puede ejecutarse de dos formas:
	•	Abriendo directamente el archivo index.html en el navegador.
	•	Navegando a cada ejercicio desde los archivos HTML individuales ubicados en src/pages/.

No es necesario ningún backend ni configuración adicional para su funcionamiento.
